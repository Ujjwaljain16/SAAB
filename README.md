# SAAB

Automation toolkit for solving Scaler assignments with Playwright and AI-assisted code generation.

## Highlights
- Persistent login/session automation
- Subject and class queue discovery
- Assignment and question traversal
- Language routing by subject
- Multi-provider solver fallback with caching

## Run
1. Install dependencies:
   npm install
2. Authenticate:
   npm run auth
3. Start solver:
   npm start
